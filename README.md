# Junior Data Analyst Assessment - iHub

This repository contains my submission for the Junior Data Analyst role at iHub, completed as part of the selection process. The assessment evaluates critical thinking, research, analytical skills, statistical proficiency, and knowledge of emerging data technologies through three sections:

**Critical Thinking, Research, and Analytical Skills:** 
Curated credible secondary datasets to support civic technology research, including data extraction, cleaning, analysis, and documentation of actionable insights. Code is provided for reproducible data processing and analysis.

**Statistical Skills:** 
Analyzed a talent_survey dataset to generate descriptive statistics, identify common programming languages, test hypotheses about industrial training sessions, assess student satisfaction using inferential statistics, and analyze course design perceptions with chi-square tests. Code for statistical analysis is included.

**Emerging Technologies:** 
Performed entity recognition, topic modeling, text summarization using transformer models, and unsupervised classification on a provided text_data dataset related to biotechnology. Extracted entities (e.g., locations, organizations), identified thematic areas, classified texts into biotech categories, and highlighted emerging industry trends. Code for NLP and machine learning tasks is shared.

# Key Skills Demonstrated:

Data curation, cleaning, and analysis
Statistical hypothesis testing and inferential methods
Natural Language Processing (entity recognition, topic modeling, text summarization)
Unsupervised machine learning for text classification
Visualization and documentation of insights

Note: The datasets (talent_survey, text_data) and detailed instructions are proprietary to iHub and not included. This repository contains the code and documentation submitted by the deadline of 1st May 2025.

# Guidelines for Use:

Place this description in the README.md file of your GitHub repository.
Ensure the repository includes your code files (e.g., Python scripts, Jupyter notebooks) and any output files (e.g., Word document, PDF, or slides) as required by the assessment.
Organize the repository with clear folders for each section (e.g., Section_1_Critical_Thinking, Section_2_Statistics, Section_3_Emerging_Tech) to make it easy for reviewers to navigate.
If you include visualizations or reports, reference them in the README with brief explanations (e.g., "See insights.pdf for documented insights from Section 1").
